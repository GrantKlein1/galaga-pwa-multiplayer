# Boss roster

Debut wave is `(index + 1) * 5`. After wave 150 the list repeats as +1, +2, …

Guests on mixed waves stay **Seraph through Overlord** only.

Health gems drop only on each id’s first-cycle dedicated debut. Dedicated kills also roll the usual 12% XP-boost gem. HP is `base * (1 + 0.8 * tier) + 72 * tier`.
